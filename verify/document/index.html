Understanding the two checks

A record and a file answer different questions

01 / Document ID lookup

Is this document registered?

A Registered Document ID means an accessible record exists in the official registry. IDs can be copied onto altered files. An ID lookup alone does not establish the authenticity of a PDF.

02 / PDF integrity

Is this the exact original file?

An Exact File Match means the SHA-256 hash of the submitted PDF matches the registered final PDF. Even a minor edit changes the file. Matching depends on registry integrity; SHA-256 is not a digital signature.

When automated verification becomes available, use the original PDF, not a scan, screenshot, recompressed copy, or print-to-PDF export. Files should be hashed on your device; only the hash and verification identifier should be sent for comparison.

How to interpret future registry results

These are explanations, not verification results for any document.

Registered Document ID
An accessible record exists. The submitted file has not been authenticated.
Exact File Match
The PDF matches the registered original byte for byte. Check its current status separately before use.
File Mismatch
The file is not identical to the registered original. Ask Deries Garment for clarification.
Document Not Found
No accessible matching record was found. Contact Deries Garment; do not infer approval.
Revoked, Expired, or Superseded
The document is no longer current or authorized for use, even if its file matches.

Restricted quotations and invoices must never expose buyer names, prices, invoice contents, or original files through a public verification link.
